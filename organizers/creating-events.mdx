---
title: Creating Events
description: How to create and configure events in SignUpBreeze.
---

Events are the core of SignUpBreeze. Each event represents something you need volunteers for.

## Creating a new event

1. Navigate to your dashboard and click **Create Event**.
2. Fill in the event details:
   - **Title** — a clear, descriptive name
   - **Description** — what volunteers need to know (what to bring, what to expect, parking info, etc.)
   - **Location** — physical address or virtual meeting link
   - **Date range** — when the event takes place
3. Save the event.

## Editing an event

From your event list, click on any event to open its overview. From there, navigate to the event details page to update the title, description, location, or dates.

Changes are saved immediately and reflected on the public event page.

## Event overview

The event overview page is your command center. It shows you the event details, shift schedule, and current signup numbers at a glance. This is where you'll spend most of your time managing an active event.

## Event slug and public URL

Every event gets a URL-friendly slug based on its title (e.g., `spring-bake-sale`). This becomes part of the public URL that volunteers use to sign up:

```
https://signupbreeze.com/e/spring-bake-sale
```

You can share this link anywhere — email, text, social media, printed flyers.
