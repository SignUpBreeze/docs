---
title: Reminders
description: How volunteer shift reminders work and how to customize when they send.
---

SignUpBreeze automatically emails volunteers to remind them about the shifts they've signed up for, so fewer people forget to show up.

## Default reminders

On every plan, volunteers receive reminders on a recommended schedule: **1 week**, **48 hours**, and **2 hours** before each shift. You don't have to set anything up — reminders send on their own.

## Customizing your schedule

On paid plans, you can change when reminders send — add your own times, remove ones you don't want, or turn reminders off entirely.

### Set an organization-wide default

Go to **Settings > Reminders** to set the default schedule for all new events in your organization.

- Leave **Use the recommended schedule** on to keep the 1 week / 48 hours / 2 hours default.
- Turn it off to build your own schedule. Add a row for each reminder — choose a number and a unit (**minutes**, **hours**, **days**, or **weeks**) **before the shift** — then click **Save**.

Each reminder must fall between **30 minutes** and **8 weeks** before a shift. Your plan sets how many reminders you can add per schedule.

<Note>Remove every row to send **no** reminders by default. New events will inherit whatever you set here unless they define their own schedule.</Note>

### Override for a single event

Open an event and select the **Reminders** tab.

- Leave **Use organization default schedule** on to follow your organization's default.
- Turn it off to set a **custom schedule for this event**. This replaces the default reminders for that event only.

Click **Save** to apply. As with the organization default, an empty schedule means that event sends no reminders.
