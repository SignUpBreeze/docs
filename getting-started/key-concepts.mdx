Understanding a few core concepts will help you get the most out of SignUpBreeze.

## Organizations

An organization is the workspace that owns everything else — its events, slots, registrations, members, and billing. Every account belongs to at least one, and you can belong to several: a PTA, a church group, a school committee, a club. Switching organizations changes which data you see across the app.

See [Organizations](/account/organizations) for switching, creating, and renaming.

### When it's called a Team

Some organizations are **calendar-driven**: instead of creating events by hand, they sync a PlayMetrics calendar and get a sign-up page per game. Those are built for sports, so SignUpBreeze calls them **Teams** — a coach setting up snack duty isn't managing an "organization".

It's the same thing under the hood. Only the word changes, and only for calendar-driven ones:

- On a calendar-driven organization, settings read **Team name** and **Delete team**. See [Team Calendars](/organizers/team-calendars).
- Everywhere else, you'll see **Organization**.
- Where both kinds can appear together — the switcher, your list of organizations — "Organization" is the umbrella term.

<Note>New accounts start with an organization named after you, like **Alex's Team**. That's just a starting value you can rename right away; it doesn't make the organization calendar-driven.</Note>

## Events

An event is the thing you're organizing volunteers for — a bake sale, a park cleanup, a weekly tutoring session, a conference. Each event has a title, description, location, and one or more shifts.

Every event gets a unique public URL (like `signupbreeze.com/e/spring-cleanup`) and a QR code that volunteers can scan to sign up.

## Slots (Shifts)

Slots are the individual time blocks within an event that volunteers sign up for. Each slot has a date, start time, end time, and a maximum number of spots.

For example, a "Saturday Park Cleanup" event might have three slots: 8am-10am, 10am-12pm, and 12pm-2pm, each with 10 spots.

## Registrations

A registration is a volunteer's commitment to a specific slot. When someone signs up for a shift, a registration is created linking them to that slot.

Organizers can view, manage, and export registrations from their event dashboard.

## Magic Links

Magic links are secure, tokenized URLs sent to volunteers after they sign up. Instead of requiring an account with a username and password, volunteers use these links to view their confirmation, manage their registration, or return to the event.

This is what makes SignUpBreeze frictionless — volunteers never need to create an account or remember a password.
